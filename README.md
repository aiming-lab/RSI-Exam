# RSI-Exam

**Benchmarking Recursive Self-Improvement through Executable Research**

[Website](https://rsi-exam.ai/)

RSI-Exam evaluates whether AI agents can improve executable research methods through sustained experimentation. Agents inherit a working method, develop and test new versions under a fixed budget, and submit a final artifact for evaluation on a hidden set.

The benchmark materials and documentation will be updated by the end of August 2026.
